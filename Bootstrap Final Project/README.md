# Vitality Gym

A responsive multi-page fitness website built with Bootstrap as a final project. The site presents a modern gym brand with a polished layout, clear navigation, and sections for programs, membership, and contact information.

## Project Overview

This project is part of the Bootstrap stage in the NTI MEAN Stack Track course and is required to complete that stage. It was created to practice responsive web design using Bootstrap 5 and custom CSS, and it includes a professional landing page and multiple related pages that work together as a complete website experience.

## Features

- Responsive navigation bar
- Hero section with strong call-to-action buttons
- Program highlights and benefits section
- Membership and contact pages
- Modern styling with Bootstrap components and custom CSS
- Footer with social media icons

## Pages

- `home.html` — Main landing page
- `programs.html` — Available fitness programs
- `membership.html` — Membership details
- `contact.html` — Contact information

## Project Structure

- `CSS/` — Stylesheets for the website
- `imgs/` — Project images and assets
- `SYS-Design/` — Design documentation and planning files

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- Material Icons
- Bootstrap Icons

## How to Run

1. Open the project folder in VS Code.
2. Start a live server (for example, Live Server extension).
3. Open `home.html` in your browser to view the website.

## Goal of the Project

To build a modern, attractive, and responsive gym website that demonstrates Bootstrap layout skills and front-end design principles.
